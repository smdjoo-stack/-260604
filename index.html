Core Elements

성공적인 프롬프트의 4대 핵심 요소

더 많이 포함할수록 AI가 의도를 정확히 파악합니다.

페르소나 (Persona)

AI가 어떤 전문가 입장에서 답변해야 하는지 역할을 부여합니다.

"너는 10년 차 시니어 PM이야."

수행 과제 (Task)

AI가 실행할 구체적인 작업을 명확한 동사로 명시합니다.

"런칭 안내 이메일을 작성해 줘."

맥락 (Context)

타겟층, 배경 지식, 제약 조건 등 상황 이해에 필요한 정보를 제공합니다.

"주요 타겟은 2030 직장인 유저들이야."

형식 (Format)

원하는 결과물의 레이아웃, 길이, 어조를 구체적으로 요청합니다.

"핵심 3가지는 불릿으로, 3문단 이내로."
Best Practices

구글이 제안하는 실전 팁

1

자연스러운 대화체 사용하기

키워드만 나열하지 말고, 동료에게 업무를 지시하듯 완전한 문장으로 설명하세요.

2

점진적인 다듬기 (반복과 개선)

후속 프롬프트로 어조와 내용을 세밀하게 조정하세요.

3

복잡한 작업은 잘게 쪼개기

단계를 나눠 순차적으로 질문하면 환각(Hallucination)을 줄이고 정교한 답변을 얻습니다.

4

AI를 프롬프트 코치로 역활용하기

막막하다면 AI에게 프롬프트 자체를 개선해 달라고 요청하세요.

Prompt Coach

AI를 프롬프트 코치로 역활용하기

스스로 지시문을 고민할 필요 없이, AI의 구조화 능력을 빌려 질문 자체를 업그레이드합니다.

Key Insight

Technique 1 · Refinement

초안 다듬기 기법

거친 아이디어를 던지면 AI가 4대 요소에 맞춰 구조화합니다.

사용자
다음 초안을 페르소나/과제/맥락/형식을 갖춘 전문 프롬프트로 다시 작성해 줘.

초안: 20명 학생 대상 10개월 보드게임 프로그램 계획안 짜줘.
AI 코치
너는 15년 차 보드게임 교육 기획자야. (페르소나)

20명 학생 대상 3~12월 10개월 커리큘럼을 기획해 줘. (과제)

전략적 사고와 협동심을 기르는 게임 타이틀·목표를 포함해. (맥락)

월별 일정·게임 이름·교육 목표를 표 형태로 정리해. (형식)

이 기법이 강력한 이유

감정선·어조 구체화
단순한 지시가 구체적인 페르소나를 입어 글의 온도가 높아집니다.

디테일한 맥락 추가
AI가 진정성 있는 결과물을 위한 구체적 소재를 유도합니다.

명확한 출력 제어
단락 구조·분량·형식을 미리 세팅해 편집 수고를 줄입니다.

Real Example · Pastor

목회자 활용 예시감사 서신 작성

목사님
5월 10일에 시설 이전·리모델링이 무사히 끝났어. 성도들에게 보낼 감사 서신 프롬프트를 다듬어 줘.
AI 코치 — 최적화된 프롬프트
너는 성도들을 깊이 사랑하는 따뜻한 담임 목회자야. (페르소나)

5월 10일 시설 이전·리모델링 완료에 대한 목회 서신 초안을 작성해 줘. (과제)

수고와 헌신을 위로하고, 새 공간에서 펼쳐질 사역의 비전을 심어줘. (맥락)

[제목–인사말–본문(감사·비전)–맺음말] 단락을 명확히 구분, 정중한 편지글 형식. (형식)
Real Example · Pastor — Image Input

소그룹 교재 이미지로프롬프트 자동 생성

기존 소그룹 교재 이미지를 AI에게 주면 — 분석 후 바로 쓸 수 있는 프롬프트를 만들어 줍니다.

목사님 — 이미지 첨부
📎 소그룹_교재_5월호.jpg

이 소그룹 교재 이미지를 분석해서, 이번 주 소그룹 나눔을 위한 프롬프트를 만들어 줘.
AI — 이미지 분석 결과
📋 교재 분석
본문: 요한복음 15:1–11 (포도나무와 가지) · 주제: 연합과 열매 맺음 · 나눔 질문 3개 확인

✅ 생성된 프롬프트
너는 10년 경력의 소그룹 인도자야. (페르소나)
요한복음 15:1–11 '포도나무' 본문을 중심으로 45분 소그룹 나눔 진행안을 작성해 줘. (과제)
교재 나눔 질문 3개를 활용하고, 일상 적용까지 연결해. (맥락)
[도입–말씀–나눔질문–기도제목] 순서, 각 단계별 예상 소요 시간 포함. (형식)
활용 팁

교재 이미지, 주보 스캔본, 필기 노트 — 어떤 이미지든 붙여넣으면 AI가 내용을 읽고 맞춤 프롬프트를 즉시 생성합니다.

Technique 2 · Reverse Prompting

역질문 유도 기법

무엇을 설명해야 할지 막막할 때 — AI에게 먼저 질문을 던지게 합니다.

사용자
교회 행사 영상을 유튜브·로비 스크린에 올리려 해. 영상 편집 가이드 프롬프트를 위해 네가 먼저 질문 4가지를 던져줘.
AI 코치 — 역질문
1. 편집 툴: 프로그램 종류와 버전은?
2. 규격: 유튜브/로비 길이와 화면 비율은?
3. 톤앤매너: 경쾌함 vs 잔잔하고 감동적?
4. 기술: Export 과정에서 특히 필요한 세팅은?
사용자 — 답변
다빈치 리졸브 18 / 유튜브 5분 가로형·로비 3분 무음 자막형 / 잔잔하고 감동적 / 화질 손실 없는 최적 렌더링
Technique 2 · Result

역질문 유도완성된 프롬프트

너는 교회 미디어 사역 10년 차 수석 편집자이자 다빈치 리졸브 전문가야. // 페르소나 다빈치 리졸브 18로 편집 구성안과 최적 Export 세팅 가이드를 작성해 줘. // 과제 유튜브(5분·가로) + 로비(3분·무음·자막). 톤: 잔잔하고 감동적. // 맥락 ① 두 버전 컷 편집 흐름 구성안 ② 화질 유지 + 용량 최적화 Export 세팅 (포맷·코덱·해상도) 구분하여 정리. // 형식
핵심 포인트

대답만 하면 완벽히 구조화된 프롬프트를 얻습니다. 빈 종이 앞에서 고민할 필요가 없습니다.

Technique 3 · Master Template

마스터 템플릿 기법

새 채팅창에 붙여넣으면 AI가 즉시 코치 모드로 세팅됩니다.

지금부터 너는 세계 최고의 프롬프트 엔지니어링 전문가야. 나의 목표는 너에게서 가장 수준 높고 정확한 결과물을 얻는 거야. 짧은 아이디어를 내리면, 즉시 답하지 말고 아래 3단계를 거쳐 줘. 1. 질문하기 — 필요한 조건 3가지 이하 핵심 질문 2. 프롬프트 제안 — 페르소나/과제/맥락/형식 적용 최적화 제안 3. 실행 — 승인 후 최종 결과물 출력 이해했다면 "어떤 작업의 프롬프트를 설계해 드릴까요?" 라고 대답해 줘.

Core Elements

성공적인 프롬프트의 4대 핵심 요소

4가지를 모두 포함할 필요는 없지만, 더 많이 포함할수록 AI가 의도를 정확히 파악합니다.

페르소나 (Persona)

AI가 어떤 전문가 입장에서 답변해야 하는지 역할을 부여합니다.

"너는 10년 차 시니어 PM이야."

수행 과제 (Task)

AI가 실행할 구체적인 작업을 명확한 동사로 명시합니다.

"신규 서비스 런칭 안내 이메일을 작성해 줘."

맥락 (Context)

타겟층, 배경 지식, 제약 조건 등 상황 이해에 필요한 정보를 제공합니다.

"주요 타겟은 2030 직장인 유저들이야."

형식 (Format)

원하는 결과물의 레이아웃, 길이, 어조를 구체적으로 요청합니다.

"핵심 3가지는 불릿으로, 3문단 이내로."
Best Practices

구글이 제안하는 실전 팁

1

자연스러운 대화체 사용하기

키워드만 나열하지 말고, 동료에게 업무를 지시하듯 완전한 문장으로 설명하세요.

2

점진적인 다듬기 (반복과 개선)

첫 시도에서 완벽한 결과가 나오지 않을 수 있습니다. 후속 프롬프트로 어조와 내용을 세밀하게 조정하세요.

3

복잡한 작업은 잘게 쪼개기

단계를 나눠 순차적으로 질문하면 환각(Hallucination)을 줄이고 정교한 답변을 얻을 수 있습니다.

4

AI를 '프롬프트 코치'로 역활용하기

막막하다면 AI에게 프롬프트 자체를 개선해 달라고 요청하세요.

Prompt Coach

AI를 프롬프트 코치로 역활용하기

스스로 완벽한 지시문을 고민할 필요 없이, AI의 구조화 능력을 빌려 질문 자체를 업그레이드합니다.

01

초안 다듬기

거친 아이디어를 4대 요소에 맞춰 구조화해 달라고 요청

02

역질문 유도

AI에게 먼저 질문을 던지게 해 필요한 맥락을 수집

03

마스터 템플릿

대화 시작에 코치 모드를 세팅해 자동으로 적용

Key Insight

이 방법은 생성형 AI의 잠재력을 100% 끌어내는 가장 강력한 기법입니다. AI가 전문가처럼 구조를 잡아주므로 사용자는 아이디어에만 집중하면 됩니다.

Technique 1 · Refinement

초안 다듬기 기법

거친 아이디어를 던지면 AI가 4대 요소에 맞춰 구조화합니다.

사용자
다음 초안을 페르소나/과제/맥락/형식을 갖춘 전문 프롬프트로 다시 작성해 줘.

초안: 20명 학생 대상 10개월 보드게임 프로그램 계획안 짜줘.
AI 코치
너는 15년 차 어린이 교육 프로그램 기획자이자 보드게임 지도사야. (페르소나)

20명 학생 대상 3~12월 10개월간 교육 커리큘럼을 기획해 줘. (과제)

전략적 사고와 협동심을 기르는 게임 타이틀 및 목표를 포함해. (맥락)

월별 일정·게임 이름·교육 목표를 표 형태로 정리해. (형식)

이 기법이 강력한 이유

감정선·어조 구체화
단순한 지시가 구체적인 페르소나를 입어 글의 온도가 높아집니다.

디테일한 맥락 추가
AI가 진정성 있는 결과물을 위한 구체적 소재를 유도합니다.

명확한 출력 제어
단락 구조·분량·형식을 미리 세팅해 편집 수고를 줄입니다.

Real Example · Pastor

목회자 활용 예시감사 서신 작성

목사님
지난 5월 10일에 시설 이전·리모델링이 무사히 끝났어. 성도들에게 보낼 감사 서신을 위한 프롬프트를 다듬어 줘.
AI 코치 — 최적화된 프롬프트
너는 성도들을 깊이 사랑하는 따뜻한 담임 목회자야. (페르소나)

5월 10일 시설 이전 및 리모델링 완료에 대한 목회 서신 초안을 작성해 줘. (과제)

세세한 수고와 헌신을 위로하고, 새 공간에서 펼쳐질 사역의 비전을 심어줘. (맥락)

[제목 – 인사말 – 본문(감사·비전) – 맺음말] 단락을 명확히 구분, 매우 정중한 편지글 형식으로. (형식)
Technique 2 · Reverse Prompting

역질문 유도 기법

아이디어는 있지만 무엇을 설명해야 할지 막막할 때 — AI에게 먼저 질문을 던지게 합니다.

사용자
교회 행사 영상을 유튜브와 로비 스크린에 올리려 해. 완벽한 '영상 편집 가이드' 프롬프트를 위해 네가 먼저 질문 4가지를 던져줘.
AI 코치 — 역질문
1. 편집 툴: 사용 중인 프로그램 종류와 버전은?
2. 플랫폼 규격: 유튜브/로비 영상의 길이와 화면 비율은?
3. 톤앤매너: 빠르고 경쾌함 vs 잔잔하고 감동적?
4. 기술적 고민: Export 과정에서 특히 정확한 세팅이 필요한 부분은?
사용자 — 답변
다빈치 리졸브 18 / 유튜브 5분 가로형, 로비 3분 무음 자막형 / 잔잔하고 감동적 / 화질 손실 없는 최적 렌더링 세팅값
Technique 2 · Result

역질문 유도 — 완성 프롬프트

너는 교회 미디어 사역 10년 차 수석 편집자이자 다빈치 리졸브 전문가야. // 페르소나 다빈치 리졸브 18로 교회 행사 영상의 편집 구성안과 최적 Export 세팅 가이드를 작성해 줘. // 과제 유튜브용 (5분, 가로형) + 로비용 (3분, 가로형, 무음/자막). 톤: 잔잔하고 감동적. // 맥락 ① 두 버전 컷 편집 흐름 구성안 ② 화질 유지 + 용량 최적화 Export 탭 세팅값 (포맷·코덱·해상도) 명확히 구분하여 정리. // 형식
핵심 포인트

"네가 먼저 질문해 줘"라고 지시하면, 사용자는 빈 종이 앞에서 고민할 필요가 없습니다. AI가 전문가 입장에서 필수 데이터를 물어보고, 사용자는 대답만 하면 됩니다.

Technique 3 · Master Template

마스터 템플릿 기법

새 채팅창에 이 한 문단만 붙여넣으면 AI가 자동으로 프롬프트 코치 모드로 세팅됩니다.

지금부터 너는 세계 최고의 프롬프트 엔지니어링 전문가야. 나의 목표는 너에게서 가장 수준 높고 정확한 결과물을 얻어내는 거야. 내가 짧은 아이디어나 지시를 내리면, 즉시 답변하지 마. 대신 아래 3단계를 거쳐 줘. 1. 질문하기 — 목표 달성을 위해 알아야 할 조건에 대해 3가지 이하 핵심 질문 2. 프롬프트 제안 — 페르소나/과제/맥락/형식을 적용한 최적화 프롬프트 제안 3. 실행 — 승인하면 제안 프롬프트 기반으로 최종 결과물 출력 이해했다면 "어떤 작업의 프롬프트를 설계해 드릴까요?"라고 대답해 줘.
